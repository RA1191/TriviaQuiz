# Trivia Quiz opdracht

## QuizAPI
QuizAPI is de backend van de TriviaQuiz en is gemaakt met springboot.

## TriviaQuizFrontend
TriviaQuizFrontens is de frontend avn de TriviaQuiz en is gemaakt in React.
Om deze te starten run terminal:
`npm run dev`

in `...\TriviaQuiz\TriviaQuizFrontend\triviaquizfrontend`.
